# AEGIS executive pitch: 9 minutes 30 seconds

The deck is deliberately shorter than ten minutes. Rehearse using a stopwatch.
Do not read every bullet or equation. Keep the separate operation video for the
submission or Q&A; playing it within the pitch requires cutting speaking time.

1. **0:00–0:40 — AEGIS.** Introduce the team and the concrete task: a client can
   inspect what an agent understood and explicitly approve a simulated change.
   State at the outset that this is a research simulator with synthetic data.
2. **0:40–1:30 — Advisory decision.** Explain the risk of a plausible narrative
   hiding a changed mandate. A successful agent needs a complete advisory flow,
   including clarification when instructions are incompatible.
3. **1:30–2:40 — Working journey.** Walk through comparison, profile and the
   example TECH/BOND/CASH instructions. Explain that the profile sets limits and
   that the client confirms the extracted bounds. The catalog is illustrative.
4. **2:40–3:35 — Language model.** Explain exactly what the model can return.
   The JSON validator blocks extra privileges, but valid JSON can still encode
   an incorrect interpretation. User review therefore remains essential. State
   that provider integration was tested with injected responses, not a live key.
5. **3:35–4:50 — Mathematics.** Point to the four objective terms: empirical
   return, tail loss, ambiguity and rebalance cost. All are in daily fraction
   units. Explain why the l1 Wasserstein ground metric gives an infinity-norm
   penalty and a linear program. Do not claim a new theorem or calibrated risk.
6. **4:50–5:35 — Conflict.** Give the incompatible EQ bounds. Explain that the
   engine returns NEEDS_REVISION, with no portfolio or execution approval. This
   is a controlled outcome, not an optimization crash.
7. **5:35–6:35 — Approval.** Describe binding to proposal, account revision and
   expiry. Explain how forged approval and replay fail. Clarify that the roles
   are local demo capabilities, not a production identity service.
8. **6:35–7:40 — Results.** Present the 51 methods and seven evidence scenarios.
   Show the actual 20% BOND / 80% CASH allocation and USD 4 fee. Without the
   client's floor, sample means make cash attractive. This is an honest model
   result, not a backtest or a promise of performance.
9. **7:40–8:35 — Evidence boundary.** Invite inspection of the source, tests,
   numerical residuals and raw events. Clearly distinguish the tested local
   execution path from untested live provider and production integrations.
10. **8:35–9:30 — Next milestone.** Describe a reviewed pilot using licensed
    products and labeled suitability cases. End by inviting judges to run a
    contradictory mandate and attempt an unapproved execution themselves.
